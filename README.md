# 六角领主 Hexlords

一个用 Python + pygame 写的回合制策略游戏，玩法致敬《英雄无敌 3》：
在随机地图上带英雄探索、占矿、捡宝、建城、招兵，在六角格战场上打仗，消灭所有对手就赢。
种族、兵种、宝物、法术全部是原创内容，规则结构参考英雄无敌 3。

## 运行

```bash
conda activate hexlords          # 已建好的环境：Python 3.11 + pygame 2.6
cd ~/Desktop/Hexlords
python run.py
```

没有这个环境的话：`pip install -r requirements.txt` 后同样 `python run.py`。

## 怎么玩

- **主菜单**：选种族、电脑对手数量、地图大小，开始游戏。
- **冒险地图**：左键点格子规划路线（绿点今天能走到，红点走不到），再点一次出发；右键看格子信息；鼠标悬停看物件和守卫。
  `E` 结束回合，`N` 下一英雄，`H` 英雄界面，`T` 城镇，空格回到选中英雄，方向键/WASD 移动视野，`F5`/`F9` 快速存读档，`Esc` 回主菜单。
- **城镇**：每天每城只能建一座建筑；兵营周产量会累积，招募的兵进入城里英雄的军队（没有英雄就进驻军）；驻军和英雄军队之间点选槽位互换，Shift+点击拆分。酒馆雇英雄 2500 金，市场换资源。
- **战斗**：按速度轮流行动。点格子移动，点敌人攻击（射手自动射击，被近身则只能近战且伤害减半）。`W` 等待（排到本回合最后）、`D` 防御、`C` 施法、`A` 自动、`R` 撤退、`F` 加速电脑动画。
- **胜负**：敌方没有城镇和英雄即被消灭；没有城镇 7 天后也会出局。

## 规则速查

| 规则 | 做法 |
| --- | --- |
| 伤害 | 每个生物掷一次伤害骰（超过 10 个按 10 次缩放）；攻 > 防每点 +5%（上限 +300%），防 > 攻每点 −2.5%（下限 −70%）；再乘攻击术/箭术/防御术、运气翻倍、冲锋加成 |
| 反击 | 近战目标每回合反击一次；远程无反击；距离 > 10 格射击减半 |
| 士气/运气 | −3…+3；正士气有 士气/12 的概率再行动一次，负士气同样概率跳过；运气 = 伤害翻倍的概率 |
| 移动力 | 由最慢兵种决定：速度 3 → 1500，每点 +60（上限按速度 11），后勤学加成；草地 100、道路 60、荒原 125、雪地 150、沼泽 175，斜向 ×1.41 |
| 经验 | 击杀敌方生物的"价值"之和；升级到 L 级需要 1000(L−1)+100(L−1)(L−2) |
| 法力 | 最大值 = 知识 ×10；每天恢复 1 + 冥想 + 宝物，在有法师塔的城里全回 |
| 城防 | 要塞/城堡/王堡：守军防御 +2/+4/+6，城堡/王堡兵种产量 +50%/+100% |

## 改数值 / 加内容

所有数据都在 `data/*.json`，改完直接重启游戏：

- `factions.json`：种族、兵种（属性、能力、价格、周产量）、兵营名字、特色建筑、中立野怪。
  加新种族：复制一个种族块，改 id/名字/7 个兵种/`dwelling_names`，再到 `heroes.json` 加两个职业和几位英雄，到 `town.py` 的 `TOWN_NAMES` 加城名。
- `spells.json`：法术（等级、消耗、伤害公式、增减益效果）。新的 `effect` 键要在 `battle.py` 的 `attack_value / defense_value / speed` 里读取。
- `artifacts.json`：宝物（槽位、品级决定守卫强度、加成）。
- `buildings.json`：建筑树（费用、前置、替代关系、收入、城防等级）。
- `skills.json`：副技能三级数值。
- `heroes.json`：职业初始四维、升级概率、技能倾向，英雄名单与专精。

## 代码结构

```
run.py                     启动
data/                      数据表（JSON）
hexlords/core/
  data.py        读表        army.py       军队 7 槽位      hexmath.py   六角格几何
  hero.py        英雄        town.py       城镇与建筑树     player.py    玩家资源
  world.py       地图、寻路   mapgen.py     随机地图         battle.py    战斗引擎（无界面）
  game.py        回合、移动与拜访、战斗收尾、胜负、存档
hexlords/ai/
  battle_ai.py   选目标：期望输出价值 − 反击损失；英雄选法术
  adventure_ai.py 建城优先级、招兵、按 价值/(1+距离) 选目标、危险评估、探索
hexlords/ui/
  app.py         场景栈 + 模态循环 + 事件分发     theme.py / widgets.py  字体、配色、按钮
  main.py        主菜单       adventure_scene.py 冒险地图    town_scene.py 城镇
  hero_scene.py  英雄/军队交换  battle_scene.py 战斗         dialogs.py 对话框
tests/
  test_core.py   规则层测试 + AI 自动跑 30 天（python tests/test_core.py）
  ui_smoke.py    无窗口渲染每个画面到 tests/shots/
  play_sim.py    模拟点击走完若干回合
```

规则层（core）完全不依赖 pygame，可以单独跑测试和 AI 对战。
